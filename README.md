LinkedIn Job Market Analysis Dashboard

An end-to-end data analytics project analyzing LinkedIn job postings to uncover hiring trends, salary insights, remote work adoption, and engagement patterns using Python and Power BI.

Project Overview

This project focuses on analyzing a large-scale LinkedIn job postings dataset to understand:

Hiring trends across industries
Salary distribution by experience and work type
Remote vs on-site job opportunities
Job engagement metrics (views & applications)
Top hiring companies
Geographic distribution of job postings

The project includes:

Data cleaning using Python
Exploratory Data Analysis (EDA)
Interactive Power BI dashboard
Business insights and visual storytelling
Tools & Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Power BI
Git & GitHub
Dataset Information

Dataset contains:

123K+ LinkedIn job postings
Salary information
Company details
Job engagement metrics
Work type and experience levels
Geographic data
Data Cleaning Process
The dataset had been collected from kaggle 

Performed extensive data preprocessing and cleaning using Python:

Removed duplicate job postings
Handled missing values
Standardized work types and salary formats
Cleaned company and location information
Validated salary and engagement metrics
Converted timestamp columns
Created derived analytical features
Exploratory Data Analysis (EDA)

Conducted detailed EDA to identify patterns such as:

Salary trends by experience level
Distribution of work types
Remote work adoption
Top hiring companies
Engagement rate analysis
Geographic hiring trends
Sponsored vs organic job performance
